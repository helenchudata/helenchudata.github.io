# Helen Chu | Data Analytics Portfolio

The homepage organizes projects by business analysis, SQL, Tableau, Python, machine learning, and R. Each project page includes a summary and links to the available work. Earlier project URLs are preserved in the existing courses directory.

## Upload to GitHub

1. Extract this ZIP.
2. Open the Code tab of helenchudata/helenchudata.github.io on the main branch.
3. Choose Add file → Upload files.
4. Upload the extracted index.html, assets folder, courses folder, and projects folder at the repository root. Upload README.md too if you want these instructions in the repository.
5. Commit to main. GitHub Pages uses main and /(root). View the published site at https://helenchudata.github.io/.

## Project files

- courses/ retains the original five project pages and supporting files.
- projects/ contains the new Python and machine-learning projects.
- Notebook HTML exports contain original code and saved outputs.
- Python Statistics Toolkit contains a source ZIP with the scripts and required input generator.
- Telecom Churn Data Preparation contains the original notebook and input datasets. Its page documents the initial ID mismatch and links to the later visual-analysis and hypothesis-testing stages.
- Duplicate PDFs, assignment grading pages, IDE settings, caches, and instructor solution files are excluded from the portfolio package.

Notebook exports can be read as static files. Re-running the machine-learning notebooks requires their original source datasets and Python dependencies.
