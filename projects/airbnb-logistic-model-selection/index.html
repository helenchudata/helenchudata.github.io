Project Summary

I used Airbnb listing data to classify superhost status. I compared a default logistic regression against a model selected through cross-validation and grid search.

GridSearchCV · Cross-validation · ROC AUC · Model evaluation

Skills and What I Learned

  • Cross-validation
  • Grid search
  • ROC AUC
  • Precision and recall

I learned to tune hyperparameters through cross-validation and compare models using multiple evaluation views. The small AUC change showed why an improvement should be judged by its size and practical relevance.

Results and Interpretation

The tuned model’s ROC AUC was 0.8243, compared with 0.8228 for the default model. Confusion matrices, precision-recall curves, and ROC curves provided several views of the small improvement.
