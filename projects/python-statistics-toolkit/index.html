Project Summary

I built Python scripts to calculate mean, median, population standard deviation, and a non-negative filter. I then refactored the statistics into reusable functions and connected them to an interactive command-line report.

I learned to turn calculation steps into reusable functions, handle odd and even list lengths for the median, and separate interactive input from calculation logic.

Project Structure

Toolkit I contains individual scripts and a sample-data generator. Toolkit II contains the calculation library and an input module. The interactive input accepts non-negative integer entries, and the calculation functions expect a non-empty list.

Project Work

Extract the source archive to inspect the scripts. For the interactive version, open the toolkit-ii folder in a terminal and run python input.py.
