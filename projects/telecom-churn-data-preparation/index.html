Project Summary

Data Preparation — Initial Stage

I inspected demographics and service records, standardized column names, converted dates and data types, and normalized marital-status values before attempting a customer-level merge.

Skills and What I Learned

  • Python
  • pandas
  • Data cleaning
  • Join validation

I learned that matching column names alone does not guarantee a successful merge. Identifier formats must agree, and row counts and matched records should be checked before calculating downstream statistics.

Initial Findings and Project Progression

Both input files begin with 7,043 records. The notebook removes one demographics record during cleaning. It also finds missing offer values and internet-related fields that need interpretation before further analysis.

The initial notebook documents an ID-format mismatch that produced an empty merge and a NaN tenure result. The later project stages use prepared customer data and successful joins to explore churn visually and test differences between customer groups.
