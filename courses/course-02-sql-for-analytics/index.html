Project Summary

LetsMeet Membership and Event Analysis

LetsMeet is a fictional platform that connects people with local interest groups and events. The MySQL project asks how members use the platform and what changes would make the database easier to maintain and report from. It connects membership, group, event, venue, category, and city data to support reporting for the platform’s stakeholders.

Skills and What I Learned

  • MySQL
  • Relational schemas
  • Data modeling
  • Reporting requirements

The LetsMeet schema helped me understand how related tables support reporting. A member can appear in several groups, so counting membership rows and counting distinct people answer different questions.

Database and Project Scope

The membership table stores one row per member and group. An analyst can count rows to measure memberships or count distinct member IDs to measure individual members. Event records can be linked to groups and venues to analyze activity by category or location.

  1. Data Impressions. Inspect the database and use MySQL queries to answer initial questions about the data.
  2. Data Reports. Summarize findings in reports for stakeholders.
  3. Normalizing Data. Improve the database structure and document the updated relationships in an entity-relationship diagram.
  4. Technical Assessment. Apply SQL skills to interview-style questions.
